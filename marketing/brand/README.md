# KoraPulse brand kit

Colours: green `#0d4f34` · gold `#f2b705` · white `#ffffff` · dark `#0d1310`. Fonts: Oswald (logo, headlines), Inter (text), Cairo (Arabic).

| File | Size | Use |
| --- | --- | --- |
| `profile-green.png` | 1080×1080 | **Main profile picture** for Instagram, TikTok, Facebook, X, YouTube, WhatsApp (made for the round crop) |
| `profile-gold.png`, `profile-dark.png` | 1080×1080 | Alternative profile pictures |
| `profile-wordmark.png` | 1080×1080 | Profile picture with the name (for places shown large, e.g. a WhatsApp channel) |
| `facebook-cover.png` | 1640×624 | Facebook page cover |
| `x-header.png` | 1500×500 | X (Twitter) header (text kept clear of the profile picture) |
| `youtube-banner.png` | 2560×1440 | YouTube channel banner (logo inside the area every device shows) |
| `logo-white.png` | 2000×640, transparent | Logo on dark photos and videos |
| `logo-green.png` | 2000×640, transparent | Logo on light backgrounds |
| `icon-white.png`, `icon-green.png` | 1024×1024, transparent | Icon only (corner of a video, stickers, thumbnails) |
| `watermark-white.png` | 640×200, transparent | Watermark for videos: put it in a corner at 60–80% opacity |
| `lower-third.png` | 1920×1080, transparent | Bar for names and titles in videos: type your text over the white part |
| `end-card-16x9.png` | 1920×1080 | Last screen of YouTube / horizontal videos |
| `end-card-9x16.png` | 1080×1920 | Last screen of Reels, TikTok and Shorts |
| `logo-mark.svg`, `logo-mark-green.svg` | vector | Icon at any size (printing, signs) |

To change a design, edit `kit.html` and run `node render-kit.js` in this folder.
